Implementation Thesis
---------------------

Build the smallest complete system that can prove the ontology-governed agent workflow:

- captures micro-agent activity as append-only telemetry,
- lets only ONTO_CONTROLLER author graph payloads,
- validates graph payloads with deterministic rules,
- derives macro-state through inference,
- displays before-processing and struggling/validation views,
- evaluates the same 10 cases against a baseline,
- and closes with lastring only after evidence is complete.

Non-Goals for the First Implementation
--------------------------------------

- Do not build a full production UI before the evidence pipeline works.
- Do not integrate private credentials or external paid services into the required reproduction path.
- Do not allow individual agents to write graph payloads directly.
- Do not make consequential repository actions without a human approval gate.
- Do not hide warning or failure states behind success-shaped fallbacks.

Risk Controls
-------------

- Graph payload authorship belongs only to ONTO_CONTROLLER.
- Risky actions must request confirmation with `ask`; they must not block the agent flow with a hard deny.
- Human reviewer approval is mandatory for final merge and lastring closure.
- All data used in evaluation must be synthetic, public, or approved anonymous data.
- Credentials and private data must not appear in graph payloads, trajectories, screenshots, or reproduction files.

Definition of Done
------------------

The implementation is complete when:

- The ontology files exist and represent all six axioms.
- The SHACL shapes reject invalid transitions, scope leaks, domain breaches, and incomplete lastring closure.
- The inference queries derive macro-state from event history.
- The graph payload demonstrates the required views and cases.
- The evaluation harness compares baseline and final solution across all 10 cases.
- The improvement changelog explains which changes improved the result and which experiment was removed.
- The reproduction guide can be followed from a clean environment.
- The final deliverables are assembled and evidence-backed.
- `REGISTER_LASTRING` reaches `DONE_HF` only after human approval.
